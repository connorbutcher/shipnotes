Projects can now be shown as a kanban board. Drag cards between columns to move work along, and colour-coded tags show what kind of work each card is at a glance.

Added

  • Kanban board layout for every project
  • Custom columns: rename, reorder or add your own
  • Work-in-progress limits per column
  • Press B to switch between list and board

Changed

  • Tags now have colours, chosen automatically and editable in project settings
